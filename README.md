# nvcode Homebrew tap

Homebrew formulae for [nvcode](https://github.com/innonex-us/nvcode), a small,
fast terminal coding agent for NVIDIA-hosted open models.

## Install

```sh
brew install innonex-us/nvcode/nvcode
```

## Upgrade

```sh
brew upgrade nvcode
```

## Uninstall

```sh
brew uninstall nvcode
brew untap innonex-us/nvcode
```

`Formula/nvcode.rb` is rendered and pushed by the nvcode release workflow on
every release, with the version and per-architecture sha256 checksums of that
release's archives. Do not edit it by hand.
